# Rahul weds Avishi · Digital Wedding Invitation

Live at [rahulwedsavishi.in](https://rahulwedsavishi.in). Its bride-side twin is [not-achilles/AvishiWedsRahul](https://github.com/not-achilles/AvishiWedsRahul).

Both sites share the same `style.css` and `app.js`; only `index.html`, the logo and the share image differ. When you change the design or animation in one, copy those two files to the other.

- `index.html` – all the text and event details (each event card's `data-cal-*` attributes feed its "Save date" button)
- `images/` – monogram, event illustrations, hero, `og-image.jpg` (WhatsApp link preview)
- `gallery/` – the four Our Story photos
